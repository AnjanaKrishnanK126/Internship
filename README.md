# Session Attended
Topic: CI/CD with Docker and GitHub

 Continuous Integration (CI)
- CI process includes:
  - `git pull` – fetching latest code from repository
  - `docker build` – building Docker image
  - Running containers from built images
  - Pushing images to container registry.
- Helps in automating code integration and testing.

 Continuous Deployment (CD)
- Automates deployment of applications after integration.
- Ensures faster and reliable delivery of applications.

 Dockerization
- Process of packaging an application with:
  - Code
  - Dependencies
  - Runtime environment
- Enables consistent execution across different systems.

 Secrets and Environment Variables
- Secrets: Used to store sensitive data (API keys, passwords).
- Environment Variables: Used to configure application settings dynamically.
- Important for secure and flexible application deployment.

 GitHub Management
- Managing repositories for CI/CD workflows.
- Understanding how GitHub integrates with Docker and CI pipelines.
- Importance of maintaining clean and organized repositories.
