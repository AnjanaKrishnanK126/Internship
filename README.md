 # Session Attended
Topic:Docker (Containers, Networking, and Commands)

Docker Images
- Images contain:
  - Application code
  - Required packages/dependencies
  - OS + application environment

Docker Containers
- Ephemeral / Stateless Containers:
  - Do not store data permanently.
  - Data is lost once the container stops.
- Stateful Containers:
  - Store persistent data.
  - Use volumes to retain data even after container stops.
 
Docker Volumes
- Used for data persistence.
- Types include:
  - Named volumes
  - Bind mounts
  - Anonymous volumes

 Docker Commands Learned
- `docker ps` – View running containers
- `docker ps -a` – View all containers
- `-d` – Run container in detached mode
- `-t` – Allocate pseudo-terminal
- `-e` – Set environment variables
- `docker stop` – Stop a container
- `docker rm` – Delete/remove a container
- `docker rmi` – Remove an image

 Docker Networking
- Bridge: Default network for containers on a single host
- Overlay: Used for multi-host communication
- Host: Shares host network directly
- None: No network connectivity
