Python Concepts
- String Functions:
  - `capitalize()` – Converts the first character to uppercase.
  - `lower()` – Converts all characters to lowercase.
  - `upper()` – Converts all characters to uppercase.
  - `title()` – Capitalizes the first letter of each word.
  - `strip()` – Removes extra spaces from the beginning and end.
  - `split()` – Splits a string into a list.
  - `replace()` – Replaces a part of the string with another value.
- Indexing:
  - Accessing characters using index positions.
- Logical Operators:
  - `and`, `or`, `not` – Used for decision-making and conditions.

SQL Concepts
- ORDER BY:
  - Used to sort data in ascending or descending order.
- Aggregate Functions:
  - `COUNT()`, `SUM()`, `AVG()` for summarizing data.
- Keys:
  - Primary Key: Uniquely identifies each record in a table.
  - Secondary Key: Used for searching or indexing (non-unique).
- Data Manipulation Commands:
  - `INSERT` – Add new records.
  - `UPDATE` – Modify existing data.
  - `DELETE` – Remove records from a table.
